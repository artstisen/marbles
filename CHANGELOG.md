# Changes

## v1.5.3
- **Login page**: the options (`Esc`) are a list with a selector, one option on each row: `j` `k` `gg` `G` select and `Enter` or `l` opens, or press the key of the option. _File/Directory_ is gone from the list (the arrow keys of the login page select them), and the log is `V` (`G` goes to the last option).
- **Configuration** (Page 2): **Text Editor only** and **Note Management only**, for running one Marbles as a text editor and another for notes. The other mode is not shown in the Mode tab, and as a text editor Marbles does not open data files. Setting `onlymode`; off after _Reset all settings_.
- **Logos**: two more built-in logos, **Reflections** (the Marbles logo with a color for each row) and **Islands** (islands with palms, drawn with a color for each cell). They can be used as they are, or edited and saved as logos of your own.
- **Logos and color schemes**: `R` in the lists renames one of your own (the setting follows when it is the one in use).
- **Logos**: a color for each cell. The Colors tab has the sub-tabs **Rows** (as before) and **Cells**, where cells are painted on the grid: `c` picks the color, `Space` paints, `x` clears a cell, `v` selects a rectangle to paint or clear, `X` clears all, `u` undoes. A cell without a color of its own has the color of its row. Saved in the logo file (`cells=`).
- **Color schemes**: a third page of colors, **Syntax 1** to **Syntax 12**: the colors of colored text in the editor, shared by Markdown, HTML, CSS, JavaScript, JSON and XML (each shown with what it is used for). New colors: **Line numbers** and **Current line number** of the editor, and **Selector** (the arrow `->` of lists, menus and settings, with a background and a text color). _Preview title_ is now **Accent**. All of them default to the colors they had.
- **Logos**: a **Colors** tab: each row of a logo can have a color of its own (or all rows one color), with the logo shown above. The colors are saved in the logo file (`colors=`).
- **Color schemes**: the label **Unsaved** of the editor has colors of its own (`unsaved`, `unsavedtext`; by default the text inverted).
- **Logos**: the logo of the start and login pages can be one of your own. _LOGOS_ (`:logo` in the main menu, or _Logo_ on the Configuration page) is a frame with two tabs: **Logos** (select and use a logo, with a preview) and **Editor** (a grid of 4 rows of 63 characters with a ruler, edited in NORMAL and REPLACE mode, with undo). Saving asks for a name and keeps the logo as a text file in `data/logos`, which is then the logo in use (setting `logo`). `:logo Name` uses a logo by its name.
- **Color schemes**: a color of its own for the **Key hints** on the bottom line (`keyhints`; by default the text).
- **Clipboard**: every yank goes to the system clipboard by default (`clipboardyank=all`); only with `"+` in front can still be chosen on the clipboard settings page.
- **Color schemes**: a highlighted focused tab keeps the color of **Tab focus** as its text (unless **Tab highlight** has a text color of its own).
- **Color schemes**: the color scheme editor is now _COLOR SCHEMES_, a frame with three tabs: **Schemes** (select and use a scheme: the built-in ones and your own), **Colors** (two pages of colors) and **Preview**. Saving the colors asks for a name and keeps them as a scheme of your own, a text file in `data/colorschemes`, which is then the scheme in use. New colors: **Tab frames** and **Box borders** (by default the dividers), and **Highlight focused tabs** on or off, with **Tab highlight** (the colors of the highlight), **Tab focus** (the name of the focused tab when it is not highlighted) and **Other tabs** (the names of the tabs not shown). The default scheme has gray box borders and no highlight: the focused tab is cyan, the others dark gray. The settings file keeps only the name of the scheme in use (`colorscheme`; the old color settings are not read). The color scheme is no longer chosen with `h`/`l` on the Configuration page or `:color` in the main menu; `:scheme Name` uses a scheme by its name.
- The exit question asks "Exit Marbles?".
- **Main menu of a data file with tabs**: the four boxes are now the four tabs of a frame with tabs (_Notes_, _Data file_, _Settings_, _Marbles_). `Tab`/`Shift+Tab` and `h` go from tab to tab, `1` to `4` select one, and `j` `k` go on into the next tab.
- **Boxes with the title in a tab**: the title of every box on top of a page (questions, messages, pickers, the snippets, the search and replace boxes, spelling suggestions, the Options menus ...) is shown in a tab above its top left corner, in the colors of the tabs, as the frames with tabs.
- **Color scheme editor** in a frame with tabs: _Colors_ (the preset and the groups) and _Preview_ (a small screen, now also with a frame with tabs). A new group, **Tabs**, sets the colors of the tab shown (background with `l`, text with `T`); by default the dividers inverted. Settings `tabcolor` and `tabtext`.
- **Start page with tabs**: the start page is a frame with the tabs _Mode_ and _Configuration_, and the settings are on two sub-tabs (_Page 1_, _Page 2_), so they fit on the screen. `Tab` and `Shift+Tab` go from page to page. The tab and sub-tab shown have the colors of the frame inverted. _Configuration_ is no longer a choice of its own (the Quick guide is now `3`, Exit `4`). The frame is a reusable control (`TabFrame`) for other pages later.
- **Snippets and string memory boxes**: while filtering, `Tab` (or the down arrow) selects the next match and `Shift+Tab` (or the up arrow) the one before.
- **Editor**: _scrolloff_ keeps lines above and below the cursor when the text scrolls (as in Vim): `:scrolloff` turns it on and off (12 lines), `:scrolloff 8` / `:set so=8` sets the number (999: the cursor stays in the middle). On by default (also after _Reset all settings_); also on the Configuration page (settings `scrolloff`, `scrolllines`).
- **Lists of a data file**: `:clipboard` shows the clipboard settings.
- **Editor**: `:dup 5` (or `:'<,'>dup 5`, `:2,4dup 5`) makes five copies of the line, the selection or the lines, as one change.
- **File browser**: `:exit` exits Marbles (asking first). `:q` still goes back to the start page.
- **String memory**: `:reglist` shows all the strings of the memory in a box (the newest first, with a preview), where they can be selected (`j` `k` `gg` `G`), filtered (`/`) and inserted with `Enter` (as `p`).
- **Snippets**: `:sn` is short for `:snip` (`:sn add`, `:sn edit`), and `CTRL+K` in Insert mode shows the snippets and inserts the one picked at the cursor, staying in Insert mode.
- **Editor**: `:spell` turns spell checking off again when it is on (as `:nospell`). `:spell da,en` (with languages) and `:set spell` only turn it on.
- **Paste bin** in the data directory: `paste-bin.txt` is now kept with the settings and the snippets (a paste bin file set as a full path stays where it is). A paste bin in the directory Marbles was started from is no longer used: move it to the data directory to keep its text.
- **Favorites**: `T` (`:top`) and `E` (`:bottom`) move the marked favorites (or the selected favorite or folder) to the top or the end of the list. Favorites in a folder go to the top or the end of the folder.
- **File browser**: `:data` goes to the data directory, with the settings, the snippets (`snippets.txt`), the favorites and the history (`:home` goes to the folder of the data files in use, which can be a subfolder).
- **Snippets** in the editor: `:snip` shows the snippets (kept in `snippets.txt` in the data directory) in a box, where they can be inserted, filtered, sorted (as in the file, by title or last used), added, renamed and deleted. `$0` in a snippet places the cursor (or, with a selection, the selected text or lines: the snippet is put around them, indented as they were), and a tag in the title (`(html)`, `(css)` ...) shows it first for that kind of text. `:snip add` keeps the selection as a snippet (asking first in a note), and `:snip edit` opens the file and returns to the text afterwards. If there is no file, it is made when asked.
- **Wrapping of long lines** can be turned off in the editor (`:wrap`, `:set nowrap`, or the Configuration page): each line is one row, the view scrolls sideways to follow the cursor, `<` and `>` show where a line goes on, and `zh` `zl` `zH` `zL` `zs` `ze` scroll the view. On by default (setting `wrap`).
- **Editor**: the paragraph text object (`vip`, `yip`, `dip`, `ap`), brackets over several lines (`viB`, `diB`, `vib`: the lines between `{` and `}` on lines of their own), `:sort` (`:sort!` reversed, `:sort i` ignoring case) for the selected lines or all, and `gm`/`gM` (half the screen width right/left). The text objects (`viw`, `vi"`, `va"`, `vi'` ...) are now in the help.
- **Unpinning**: `P` on a pinned favorite offers to unpin it (`U`) and keep it as a favorite, besides removing it from the favorites.
- **System clipboard and paste bin**: yanked text can also go out of Marbles: to the system clipboard through the terminal (OSC 52: Windows Terminal, iTerm2, kitty, WezTerm, tmux, also over SSH), and/or to a paste bin file (`paste-bin.txt`) for terminals without it, as the console of a Raspberry Pi. By default with `"+` in front (`"+yy`, `"+y` on a selection), or for every yank; never for deleted text. `:pb` and `:pbappend` write the selection (or the text) to the paste bin, `:pbread` inserts its text, `:pbclear` empties it. `:path` (in the file browser and the editor) copies the full path of the selected file or the file being edited. A new page, _Clipboard_ (`:clipboard` in the main menu and the editor, and on the Configuration page), has the settings, among them whether text may be sent out of the notes of a data file (off until allowed).
- **Logo**: drawn with "M" instead of "#", and with fewer dots and dashes, which looks better in more terminals (as on the Raspberry Pi).
- **File browser**: `:match` makes the other pane show the directory of the pane with the focus.
- **Color scheme editor**: moving the selection only moves the pointer, instead of drawing the whole page again.
- **Entries open in the editor**: opening an entry (from a list, `R`, `:import`) goes straight to the editor, and closing the editor returns to the list it was opened from, with the entry selected (or to the main menu). The page that showed the entry before it was edited is removed, and what could only be done there is done in the lists, on the selected entry: `I` or `:info` (dates, words, characters, lines and syntax in a box), `:duplicate`, `:revert`, `:export` and `:import`. `:revert` now changes the saved entry too (before, the reverted text was only kept when the entry was edited afterwards).
- **Login page**: the data directory is shown by its name, "Directory: data" (and "data/notes" for a directory in it), instead of "~", which on Linux and macOS stands for the home directory.
- **Duplicate in the editor**: `:dup` (or `:duplicate`) copies the selection right after itself: text selected with `v` after its last character, lines selected with `V` below them, a block selected with `Q` to its right. Without a selection it duplicates the line of the cursor (`:2,5dup` lines 2 to 5).
- **Picking the color scheme and the language**: `:color` and `:language` in the main menu, and `Enter` on _Color scheme_ and _Language_ on the Configuration page, show the choices in a box on top of the page (`j`/`k`, `gg`/`G` or the number, and `Enter`). The last choice of the color schemes opens the color scheme editor. `h`/`l` on the Configuration page still select the previous/next, and `:color 5` and `:language da` still select at once.
- **Automatic size off** (`:size auto`, or the Configuration page) goes back to the default size.
- **Entries remember their syntax colors**: `:syntax md` (or `html`, `css`, `js`, `json`, `xml`) when editing an entry is kept in the entry, as the favorite and pin tags (a letter in its options, in the encrypted data file), so it is colored when it is opened again. `:syntax off` removes it. The lists show the kind (_MD_, _HTML_ ...) before the date, and the info box (`i`) tells the syntax. Earlier versions of Marbles ignore the tag.
- **Colors of pinned entries**: `C` in the favorites list of a data file opens the list of colors for the selected pinned entry, as `C` in the favorites of the file browser. The command `:pin` is renamed `:color` (`:color 13` picks color 13 directly).
- **Lists of entries** (All, Top 20, Favorites, Session history, Search): the kind of list is shown at the top left (_ALL_, _TOP 20_ ...), the keys at the top are replaced by the most used keys on the bottom line, and `?` shows the keys of the lists in a section of the help of its own. A page has room for more entries. `gg` and `G` select the first and last entry of the whole list (going to the first/last page); `Home` and `End` go to the first/last page.
- **Main menu**: `l` (or `Right`) and `Space` open the selected item, as `Enter` (`Space` turns a setting on or off; it no longer opens the favorites, which is `F`). In the lists, `-` returns to the main menu, as `Esc`; `h` still shows the previous page. `?` shows the keys of the main menu in a section of the help of its own.
- **The year of a new calendar and the summaries of merge and export** are shown in boxes on top of the page (`h`/`l` change the year). The Danish texts say "tast" (as in "tast Enter") for the keys.
- **All questions and messages in boxes**: the remaining questions and messages that had a page of their own are shown in a box on top of the page: delete, duplicate, revert, undo deletion, add to/remove from favorites (with _Pinned_/_Pin_ as a third choice), "Entry deleted" and the other messages, "No entries found" (All, Top 20, Favorites, Session history), the export questions, the questions and names when a data file is created, renamed, copied, moved or deleted from the login page, the choice of merge or export, the messages of the merge tool, and errors. The questions no longer end with "[Y] Yes [N] No": the box shows the choices, which are picked with their key (`Y`, `N` ...) or with `j`/`k` and `Enter`. While the data file is saved, "Saving..." is shown on the bottom line instead of on an empty page.
- **More boxes on top of the page in a data file**: the timestamp (`D`), `:import`, `:transfer` (its choices, the key and its messages) and `:backup` (its questions and messages) are shown in boxes instead of on pages of their own, and so are the search text (`S` or `/`, starting with the last search; "No entries found" as well), the title of a new entry (`N`) and a changed title (`:title` in All, Top 20, Favorites and Session history, and `T` when viewing an entry). After `:title` in a list the list is shown again. When one box follows another, the new box covers the one before it.
- **Wrong password**: on the login page (and when resetting the password) "Invalid password. Make sure Caps Lock is not enabled." is shown in a box on top of the page instead of on a page of its own. While the data file is read, "Loading..." is shown on the bottom line of the login page.
- **Data file info** (`I` in the main menu and in the options of the login page): shown in the same box as the file info of the file browser, on top of the page, with the number of entries (when logged in) and the backup directory as well. The labels of the box take the width of the longest label, so longer translations fit.
- **File history**: `O` or `:history` in the file browser shows the files opened in the editor from the file browser, the last opened first, with the time each was opened (at most 100: the oldest are dropped). From the list a file can be opened (`Enter`), shown in the file browser (`B`), added to or removed from the favorites (`P`, a favorite has a `*`), taken out of the history (`D`) or the whole history cleared (`X`, asks first in a box), and the list can be filtered (`/`). It is kept in `history.txt` in the data directory. Its commands are logged by name, and taking a file out of the history or clearing it is logged as well. The key hints of the file browser show `O History` instead of `/ Filter` (`/` still filters).
- **File browser, several files at once**: `Space` marks files and directories (a `+` in front, the number marked at the bottom right), as in the list of favorites. `Y` (duplicate), `C` (copy), `M` (move), `P` (favorite) and `D` (delete) then work on all the marked ones. `Esc` clears the marks.
- **Copy and move in the file browser**: with two panes, the focus stays in the pane copied or moved to afterwards (with the file selected there) instead of going back. While the place to copy or move to is selected, the label at the top left ("COPY TO: 2 MARKED") and the name of the pane with the focus are shown in the attention color.
- **Questions in a box**: the file browser and the list of favorites ask in a box on top of the list instead of on a page of their own (delete, convert a file that is not UTF-8, copy a data file to the data directory, remove favorites), and so do Exit on the Select mode page, Reset all settings and Restart on the Configuration page, and Save changes in the color scheme editor, as well as Exit (`:q`, `:exit`), `:restart`, `:defaults` and `:password` in the main menu and the other pages of a data file. Names are typed in a box as well (`N` new file, `A` new directory, `X` rename, and new and renamed favorites folders). `Y`/`N` answer at once, `j`/`k` and `Enter` select, `Esc` cancels; for what cannot be undone, _No_ is selected first.
- **Names of files**: when a new file, directory or data file is created, or one is renamed or copied, the message tells what is wrong with the name instead of "Invalid file name": that a file or directory with that name already exists, which character cannot be used, that it ends with a dot or a space, that it is too long, or that Windows keeps the name (`CON`, `NUL`, `COM1` ...). The rules are the same on Windows, macOS and Linux, so the files can be copied between them.
- **Editor**: _EDITOR_ is shown at the top left and `:help` at the top right (the name of the data file is not shown in the editor). The line above the text is a plain line that tells what the keys do: NAVIGATE (Normal mode), EDIT (Insert mode), SELECT (the Visual modes) or COMMAND (a command or search being typed), in the language of Marbles. " Unsaved " has a blank space on each side, and the mode at the bottom ("-- NORMAL --") is followed by a blank space before the line starts (a message such as "Saved" comes right after that space). Line numbers are off until turned on. `gg` and `G` select the first and last choice in the save box of the editor and in the Esc box of the main menu.
- **A new main menu**: the four pages of the menu are now two, each with two boxes: _Notes_ and _Data file_ on the first page, _Settings_ and _Marbles_ on the second. _MENU_ is shown at the top left, as on the other pages. The items can be selected with `j` `k` and opened with `Enter`, `Tab` goes through the four boxes of the two pages (numbered 1 to 4 below them; the box with the selection has a highlighted title and number), `j` and `k` go on into the next or previous box, and `gg`/`G` select the first/last item of all, and the keys are shown at the bottom, as in the file browser. `Esc` shows a box to log out, go to the Select mode page or exit. The preview of the last edited entries (`P`) is removed, and so is its setting `preview`.
- **The vignette is removed**: `:vignette`, the text shown on the main menu, the vignette entry of new data files and calendars, and the setting `vignette`.
- **Start page**: the name of the selected data file is no longer shown at the top right (it belongs to the login page). In the options of the login page (`Esc`), `F/T` (Files/Select mode) is now the first item, and `I` (Info) has taken its place.
- **A new logo**: "Marbles" in the style of block letters, drawn with ordinary characters. It is now the only logo: the logo presets, `:logo`, the Logo row of the Configuration page and the settings `logo` and `logotxt` are removed. The sweep of the logo on the login page is twice as fast.
- **Color scheme editor**: the colors are edited on a page of their own, opened with `:scheme` or from the Configuration page (Color scheme, `Enter`). Choose a preset to start from, pick the colors of each group from a list, and see them all on a small screen at the bottom before saving with `S`. Menu page 4 now holds `:scheme`, `:color` and `:bw`. The colors can also be edited while black and white is on.
- **Start in the favorites**: when Marbles starts in the Text Editor, it can open the favorites list of the file browser first (Configuration page, below "Start in Text Editor").
- **Languages**: the menus, help, quick guide and messages can be shown in Danish, German, Norwegian (bokmål), Swedish, Spanish or French. Choose the language on the Configuration page of the start page, or with `:language da` (and so on) in the main menu (saved as `language` in the settings file). Commands, keys and the names of the editor modes stay English in all languages. Lines of help and key hints that are too long for the window in a language are cut at its edge.
- **`gv`** in the editor selects the last selection again (as in Vim), in the same kind of selection.
- **Lists**: `:ol` makes the selected lines a numbered list and `:ul` a bulleted list (Markdown). Used again on the same lines, the list marks are removed. Indented lines are numbered as a list of their own.
- **Visual block** in the editor: `Q` (or `:block`) selects a block, the same columns on each of the lines. `I` and `A` type text in front of or after it on every line, `d` `y` `c` `p` `r` and the case changes work on the block, `$` extends it to the end of each line, and a yanked block is pasted as a block. `:vsel` and `:vline` start the other two kinds of selection, and `v` `V` `Q` switch between them.
- **A background color for the color scheme.** The color scheme editor on menu page 4 has a new last group, _Background_. `[Default]` keeps the terminal's own background (also when it is transparent), which is still the default; a color fills the whole window with it. Saved as `background` in the settings file.
- **The name at the top of the pages** is now shown as `-- Marbles --` (it was `*** Marbles ***`), and so is the text shown when Marbles exits.
- **A new color preset, Deep Blue**, the second of the presets (`:color 2`): gray text on a dark blue background, with cyan, green and magenta. The other presets follow it, one number higher than before.
- **Tab completes commands.** On the command line, `Tab` completes the command being typed (`:und` `Tab` gives `:undelete`). `Tab` again gives the next command that starts the same, `Shift+Tab` the previous, and after the last one what you typed is shown again. With nothing typed, `Tab` goes through all the commands of the page you are on, so it also works as a way to find a command. Each page and the editor completes to its own commands.
- **Editor**: `:d` (`:delete`) and `:y` (`:yank`) without lines in front work on the line of the cursor.
- **More room in the main menu.** When a data file is open, the top of the menu pages shows `-- Marbles --` like the lists do, instead of the big logo (which is still shown on the start and login pages). The menu starts four rows higher, which leaves more room for the preview and the vignette. The "Welcome to Marbles" text shown at the bottom after login is removed.
- **Favorites of the file browser**: `:expand` opens all the folders and `:collapse` closes them all.
- **Color picker**: `l` (or `Right`) picks the selected color, like `Enter` and `Space`.
- **Saving keeps the creation time of a file.** Text files, data files and the settings file got a new "Created" time every time they were saved, because a save replaces the file with a new one. The time is now kept on Windows and macOS. Linux does not let a program set it.

## v1.5.2
- **Colors for HTML, CSS, JavaScript, JSON and XML** in the editor, besides Markdown: comments, strings, keywords and tags, names and numbers. Files are colored by their kind when opened from the file browser, `:syntax` turns the colors on and off, and `:syntax html` (or `md`, `css`, `js`, `json`, `xml`) colors any text as that kind. The setting `mdcolors` is now named `syntaxcolors`.
- **Quick guide**: a short introduction to the two parts of Marbles, the keys for moving around and the modes of the editor. It is found on the start page, in the options of the login page (`Esc`, `U`) and with `:guide` on the first page of the main menu.
- **Line numbers** in the editor: they are on from the start. `:number` (or `:nu`) shows or hides them, in the editor and on page 2 of the main menu, and the Configuration page has a setting for it. The choice is remembered.
- **Editor, text files**: `:e` reads the file from disk again (`:e!` also when there are unsaved changes), and the bottom line shows the type, encoding and line endings of the file (`HTML UTF-8 (BOM) CRLF`).
- **Search for files** in the file browser (`S` or `:find`): by name (with `*` and `?`), by text in the files, with regular expressions, in a directory and its subfolders. The files found are shown in a list where they can be opened at the line found, shown in the browser (`B`), inspected (`I`) and added to the favorites (`P`).
- **Two panes in the file browser**: two directories are shown side by side. `Tab` goes to the other pane, and copy (`C`) and move (`M`) start in the directory of the other pane, so `S` copies or moves to it at once; the place is selected in the panes themselves, so you can go anywhere in either pane first. `T` or `:panes` switches between two panes and one. The directories of both panes are remembered (`browsedir1`, `browsedir2`, `browsepane` and `browsedual` replace `browsedir` in the settings file).
- **File browser columns**: the list has a column for the type of each item (`<DIR>`, `[Data file]`, or the extension of the file such as `TXT` and `MD`) and one for the size, so they line up.
- **Favorites of the file browser**: `-` (and `Backspace`) closes the list, lowercase `v` moves a favorite like `V`, and `u` or `:undo` puts back the favorite or folder that was removed last.
- Lowercase `v` also moves a pinned entry in the favorites list of a data file.
- The color lists show `[Default]` in the normal text color instead of "Default" in green.

## v1.5.1
- **Select mode at startup**: Marbles starts with a choice between _Note Management_ (the login page), _Text Editor_ (the file browser) and _Configuration_, where it can be set to start directly in one of the two (`startmode` in the settings file). From the login page the choices are reached with `Esc`, `T`.
- **Export**: `:export` lets you select the directory in the file browser and enter the file name (the title of the entry is suggested), asks before replacing an existing file, and shows where the file was saved.
- **New entry from the command line**: `:new My title` creates an entry with the title and opens it in the editor. `:new` alone asks for the title.
- **Esc closes the editor**: in Normal mode `Esc` works as `:q` (it asks what to do with unsaved changes). It still leaves Insert and Visual mode, cancels a half typed command and removes the search highlighting first.
- **Deleting an entry** asks for confirmation once instead of twice (a deleted entry can be brought back with `:undelete`).
- **Colors of pinned entries**: `:pin` in the favorites list shows a list of 16 text colors to pick from (`:pin 13` picks by number). Pinned entries are shown as colored text instead of with a highlighted background. The three highlight styles of earlier versions (`:pin 1-3`) are shown as cyan, yellow and red.
- **Find-and-replace box**: `:replace` in the editor shows a box with the text to find, the replacement and options (match case, regular expression, whole text/current line/selected lines), as an alternative to writing a `:s` command. A word selected in the text is filled in as the text to find.
- **Spell checking commands**: `:spellnext`, `:spellprev`, `:suggest` and `:spelladd` do the same as `]s`, `[s`, `z=` and `zg`.
- **File management in the file browser**: create directories (`A`), rename (`X`), duplicate (`Y`), copy (`C`) and move (`M`) to another directory, and delete (`D`) files and directories, also as commands (`:mkdir`, `:rename`, `:duplicate`, `:copy`, `:move`, `:delete`). Nothing is overwritten, and what Marbles is using is protected. Deleted files cannot be recovered.
- **Editor**: the question about unsaved changes when closing is a box on top of the text instead of a page of its own, and "Unsaved" is highlighted. "[Not encrypted]" is only shown for text files opened while logged in to a data file.
- The key hints at the bottom of the file browser and the favorites have highlighted keys.
- **Terminal window made smaller**: the start page, the file browser, the favorites and the help follow the size of the window when automatic size is on. When the dimensions no longer fit the window, the page is drawn again afterwards, and with a fixed size you are offered to switch to automatic size.
- **Markdown colors** in the editor: headings, bold, italic, code, links, quotes, list markers and rules are colored. Markdown files (`.md`) are colored when opened from the file browser, and `:syntax` turns the colors on and off in any text.
- **Log**: commands and the file operations of the file browser are logged, the log holds the latest 1000 lines, long lines continue on the next row, and `/text` only shows the lines containing a text. Commands in the menus and the editor are logged by name only, so no text from your notes is in the log.
- The Configuration page has _Restart Marbles_ and _View log_.
- **Help for the page you are on**: `?` (and `:help`) shows the keys of the current page: start page, login page, menus and lists, file browser, file favorites or editor. `?` in the help switches to all keys and back. The start page and the login page have their own help sections.
- **Black and white**: a setting that shows everything in black and white without changing your color scheme (`:bw` on menu page 4, or the configuration page; `monochrome` in the settings file).
- The start page has a fourth choice, _Exit_, that closes Marbles without asking.
- **Configuration page** (start page): besides what to show at startup, it now has black and white, color scheme, logo, automatic or manual size, and reset of all settings.
- The second choice on the start page is named "Text Editor/File Management", and the file info box (`I`) is also available in the list of favorites.
- **File browser**: `:new name` creates a file (as `N`), and `I` or `:info` shows the type, size, dates and path of the selected file or directory.
- **Favorites in the file browser**: `P` marks a file or directory as a favorite, and `F` shows the list of favorites, where they can be opened, shown in the browser (`B`), moved up and down (`Tab`/`V`), given a color (`C`), searched (`/`) and removed. The list is kept in `favorites.txt` in the data directory. Favorites can be grouped in folders (`A`), which open and close with `Enter`; several favorites can be marked with `Space` and moved to a folder (`M`) or removed (`D`) in one go; a favorite is put in a folder by moving it onto it, and folders can be moved, renamed (`X`), colored and removed.
- **Moving pinned entries**: `Tab` or `V` in the favorites list highlights the selected pinned entry, which then follows `j` `k` up and down among the pinned entries until `Esc` is pressed (earlier `Tab` moved it to the top).
- **Color scheme editor** (`:scheme`): colors are picked from the same list of 16 colors (`l` or `Space`, and `T` for the text color of the highlight styles) instead of stepping through them.
- The version number on the login page is placed correctly next to the logo.
- The color settings page says "Editor title" (the scroll indicator no longer exists).

## v1.5.0

### Upgrading from v1.0.x: read this first
- **Data files are converted, and the conversion is one-way.** The first time you log in to a data file from an earlier version, Marbles saves it in the new file format. Earlier versions of Marbles cannot open the converted file.
- **A copy of the original is kept.** Before converting, Marbles copies the original file to `<name>.mbls.legacy` in the same directory. The copy is still encrypted the old, weaker way. Delete it when you have checked that your notes are in place.
- **The keys have changed.** The `CTRL+W` shortcuts are gone. Marbles is now operated in the style of Vim (see below). Press `?` anywhere for the list of keys.
- **.NET 10** is required instead of .NET 6.
- Your `settings.ini` is read as it is. The key mapping settings (`kbtrigger`, `kbsave` ...) no longer exist and are removed the next time Marbles saves the settings.

### Encryption
- The encryption key is derived from the password with PBKDF2-HMAC-SHA256 (600,000 iterations and a random salt). Earlier versions used the password itself as the key.
- Data files are encrypted with AES-256-GCM, using a new random nonce for every save. A wrong password, a damaged file and a file that has been tampered with are all detected.
- Passwords can be up to 128 characters, and all characters count (earlier versions treated all non-ASCII characters as the same character).
- Generated passwords (`:pw` in the editor) come from a cryptographic random number generator.

### Safer saving
- Data files, backup files and the settings file are written to a temporary file that then replaces the original, so an interrupted save cannot leave a half written file.
- A data file whose content cannot be read is no longer opened as an empty file (saving it would have overwritten the content). Characters that cannot be stored are removed when saving, and files from earlier versions containing such characters are recovered when loading.

### New editor
- Normal, Insert and Visual modes, with the mode shown on the bottom line together with the cursor position.
- Vim movements, counts, operators and text objects (`dw`, `ciw`, `3dd`, `yy`, `p` ...), undo/redo in steps, and repeat (`.`).
- Search with regular expressions (`/` `?` `n` `N` `*`) and find-and-replace (`:s/old/new/g`, `:%s/old/new/g`).
- A command line (`:w`, `:q`, `:wq`, `:5`, `:help` ...).
- In V-LINE mode `J` and `K` move the selected lines down and up.
- Lines are wrapped at blank spaces, and wide characters and emoji are handled.
- Pasting text is fast, and text copied from the terminal window no longer includes padding or the scroll marker.
- Spell checking with the spell files of Vim/Neovim (`.spl`): `:spell da,en` marks the misspelled words, `]s` `[s` go to the next/previous, `z=` shows suggestions to pick from and `zg` adds the word to your word list. The spell files are placed in a directory named `spell`.
- See the [guide to the editor](Guide-to-editor.md).

### Menus and lists
- `h`/`l` change menu page, `j`/`k` select in lists and scroll the text of an entry, `gg`/`G` go to the first/last, `/` searches and `?` shows help.
- A command line (`:`) replaces the `CTRL+W` shortcuts: `:delete`, `:transfer`, `:size`, `:color`, `:q` ... The commands are shown in the menus.
- On the login page, `Esc` opens the options menu.
- `:color 5` and `:logo 3` select a color or logo preset by number.
- `:size auto` makes Marbles follow the size of the terminal window.
- `P` on the first page of the main menu shows a preview of the 5 last edited entries, where an entry can be selected and opened.
- `:import` and `:backup` use the file browser to select the file to import and the backup directory. Any text file can be imported (earlier only "import.txt" in the data directory).
- The command line is highlighted while typing.
- The help (`?`) is shown in pages that can be browsed both ways and searched (`/text`, `n`, `N`). It also covers the file browser.
- See the guides to the [main menu](Guide-to-main-menu.md) and the [login page](Guide-to-login-menu.md).

### File browser
- From the options of the login page (`Esc`, `F`): browse directories and edit plain text files in the editor, without logging in to a data file. New files can be created.
- Text files are saved as UTF-8 with their line endings kept. Files in other encodings can be converted, replacing the file or as a copy.
- Opening a data file from the browser selects it on the login page.
- `:browse` opens the browser when logged in to a data file. Opening a file from it logs out.
- See the [guide to the login page](Guide-to-login-menu.md#file-browser).

### Other
- The logo is drawn with a sweep on the login page (`logoanim=false` in the settings file turns it off).
- The settings file is read by setting name, so the order of the settings does not matter.
- Sorting entries by title is by character order on all platforms.
- Fixed: the application could crash after a very long session of key presses.
- Fixed: changing menu page while viewing an entry could erase part of the "Created" date.
